## 저렴한 VPS의 실제 월 비용: 백업·IP·패널·트래픽

Evoxt 가격표에서 먼저 볼 항목은 백업이다. 모든 VM에 주간 오프사이트 백업이 무료로 포함된다. 저가 VPS에서 백업이 유료 애드온인 경우가 많은데, 여기서는 추가 비용이 없다.
